# 토큰 효율 협업 원칙

> (본문 정본은 `skills/common-token-efficient-collaboration/SKILL.md`) 배경만 남음

## 배경

"에이전트들이 서로 연계하며 동작하면 토큰을 많이 쓴다. 토큰을 아끼다 문제 해결을 못 하는 것보다는 적절히 쓰는 게 낫지만, 방만하게 쓰는 것은 절대 안 된다. 토큰은 절대 수치가 제한되어 있으니 에이전트들은 효율적이고 줄이는 방향으로 소통해야 한다."

이 원칙은 **모든 에이전트**에 적용된다. 특히 PM이 하위 에이전트를 호출하고 결과를 통합하는 **다중 에이전트 협업**에서 토큰 낭비를 막는 공통 규범이다.

## 실행형 본문은 Skill 참조

파일 저장·경로 반환, 압축 반환, 위임 프롬프트 설계, 팀 규모 조정, 재작업 방지, 턴 예산 통제, 서브에이전트 감독 등 구체 원칙·체크리스트는 Skill `common-token-efficient-collaboration`(`skills/common-token-efficient-collaboration/SKILL.md`)이 정본이다. 이 문서에는 더 이상 실행형 내용을 중복 기재하지 않는다.
