문서형 HTML 제작 스타일 가이드

맑은AI 개발방법론 핸드북의 디자인 시스템을 축약한 샘플이다. 색상·타이포·컴포넌트를 그대로 재사용해 제안서·보고서·핸드북 등 문서형 HTML을 만들 때 참조한다. 각 블록 위 라벨이 사용할 클래스명이다. 이 문서 자체가 .page 2장으로 구성된 인쇄 가능한 예시다 — Cmd+P로 그대로 PDF 저장해보면 페이지 처리 결과를 바로 확인할 수 있다.

PDF 출력 방법 — 페이지 처리 체크리스트
새 문서를 PDF로 뽑기 전에
  • 콘텐츠 한 장(章)마다 <section class="page">로 감쌌는가? (섹션마다 자동으로 다음 장으로 넘어감)
  • 각 page 안에 .rh(러닝 헤더) / .content / .rf(러닝 푸터, 페이지 번호)를 넣었는가?
  • 브라우저 인쇄 시 대상: PDF 저장 · 여백: 없음(None) · 배경 그래픽 인쇄: 켜짐으로 설정했는가? (꺼지면 배경색·박스가 다 사라진다)
  • 자동화가 필요하면 Playwright/Puppeteer의 page.pdf({format:'A4', printBackground:true})를 쓴다 — @page{size:A4;margin:0}와 짝을 이룬다.
  • 표·박스가 페이지 경계에서 잘리면 그 요소에 avoid-break 클래스를 붙인다(break-inside:avoid).

구성 원칙 — 각 섹션은 ① keyline 요약 → ② 본문(표·다이어그램) → ③ chklist 순으로 배치한다. 새 문서를 만들 때는 이 파일을 통째로 복사한 뒤 <section class="page">를 필요한 장 수만큼 반복하면 된다.
