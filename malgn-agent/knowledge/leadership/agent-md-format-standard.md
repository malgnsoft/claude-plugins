# [ARCHIVE — 폐기됨] 에이전트 MD 표준 포맷 (구버전)

용도(구버전 당시): malgn-agent 플러그인 에이전트 MD 파일의 공통 구조 정의

> 본 문서의 7섹션 포맷(헤더+skill_score 주석 → 핵심 원칙 → 스킬 정의 표(배점/현재점수) →
> 경험 이력 → 지식 참조 → 금지사항및승인필요작업 → 토큰효율)은 실제 에이전트 MD 어느 것도 따르지
> 않아 **폐기**한다. 정본은 `agent-training-guide.md` 부록의 9단 골격이다:
> `frontmatter(name/description[/tools]) → 핵심 원칙 → 역할 경계 → 스킬 상세(있으면) →
> 전제 조건 → 자기 검증 → 산출물 → 학습 자료(필수/참고 2단) → 토큰 효율`.
> 본문은 원문 그대로 보존하며, 신규/기존 에이전트 MD 작성·수정 시 참조하지 않는다.
> 본문 중 "표준", "정본" 등의 표현은 모두 구버전 당시 표현으로만 읽는다.

---

## 포맷 철학

**최소 MD, 최대 Knowledge.** MD는 역할 정체성·원칙·토큰 규율·knowledge 경로만 담는다.
스킬 상세·절차·예시·체크리스트는 knowledge 파일에 위임하고 MD에서 경로로 참조한다.
MD가 짧을수록 세션 로드 비용이 낮고, knowledge가 풍부할수록 실제 품질이 높다.

## 섹션별 작성 가이드

### 헤더

- **역할 1줄**: "무엇을 만들어 누구에게 전달하는가"를 동사로 명시. 추상적 형용사 금지.
  - 나쁨: "전문적인 아키텍처 설계를 담당하는 전문가"
  - 좋음: "PRD를 받아 시스템 구조·API·데이터 모델을 설계하고 개발팀에 전달"
- **모델**: 고난도 추론·조율이면 opus, 일반 실무면 sonnet. `bin/skill-definitions.js`(이 플러그인 미번들) 참조.
- **skill_score 주석**: `bin/sync-agents.js`(이 플러그인 미번들)가 있으면 자동 갱신, 없으면 수동 산정.
- **last_trained**: trainer가 학습 완료 시 갱신.

### 핵심 원칙

- 5개 이내. 많으면 읽히지 않는다.
- "무엇을 하라/하지 말라"의 행동 문장.
- 추상(성실, 정확, 전문적)은 금지. 관찰 가능한 행동만.
- 좋은 예: "산출물에서 프로젝트명만 바꾸면 다른 데도 쓸 수 있는 문장은 삭제한다."
- 나쁜 예: "항상 정확하고 전문적인 결과물을 작성한다."

### 스킬 정의

- 핵심 스킬 5~8개. 배점 합산 100점.
- 배점은 역할 핵심 가치에 비례해서 차등 부여 (모든 스킬이 동일 배점이면 설계 실패).
- 현재점수는 `bin/sync-agents.js`(이 플러그인 미번들, 있으면 사용)가 1~5로 계산 → × 배점/5로 환산.
- 스킬별 설명은 "어떤 산출물을 만드는가"를 명시.

### 경험 이력

- **프로젝트 경험**: 에이전트가 참여한 실제 프로젝트. 기여는 구체적으로.
- **소소한 학습 이력**: trainer가 지식을 주입할 때 1줄 이력 추가. malgnai-hub `agent_learning_record`와 병행.
- **경험 점수**: 아래 "경험 점수 적립 기준" 참조.

### 지식 참조

- MD에 지식을 다 담지 말고 경로만 나열.
- common/ 공통 파일 + 역할별 전용 파일.
- 파일이 없으면 경로 추가 전 먼저 파일 생성.

### 금지/승인

- skill-definitions.js EMPLOYEE_CARDS에서 그대로 가져온다.
- 동기화 포인트: skill-definitions.js 변경 시 MD도 갱신.

### 토큰 효율

- 리더형(pm, reviewer, trainer, capture-strategist): 서브 감독 항목 포함.
- 실행형(dev, designer, writer 등): 자기중단 + 압축 반환만.

## 경험 점수 적립 기준

| 이벤트 | 점수 |
|--------|------|
| 프로젝트 완료 참여 | +5점 |
| 재작업 없이 1회 통과 | +3점 |
| 리뷰어 Critical 0건 | +2점 |
| 소소한 학습 이력 추가 (trainer 주입) | +1점/건 |
| 재작업 발생 (trainer 기록) | -2점 |

**최대 경험 점수**: 100점
**경험 점수 최종 반영**: 최종점수 = 스킬점수 × 0.8 + 경험점수 × 0.2
