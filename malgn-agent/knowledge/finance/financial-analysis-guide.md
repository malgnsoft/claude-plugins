# 재무 분석 가이드

> 재무 분석을 "느낌상 남는 장사"에서 **가정·산식·출처가 박힌 검증 가능한 모델**로 끌어올린다. 모든 수치는 ① 가정(assumption) 명시 ② 산식 노출 ③ 출처/근거 — 셋이 따라붙어야 한다. 근거 없는 단정은 평범함의 신호. 3~5년 추정 모델 템플릿은 `financial-model-templates.md` 참조.

## 0. 가정 명시 원칙 (가장 중요)

재무 추정은 본질적으로 가정 위에 선다. **가정을 숨기면 신뢰를 잃는다.**

- 모든 모델 상단에 **가정 표(Assumptions)**를 둔다: 단가, 성장률, 전환율, 이탈률, 할인율, 인건비 등.
- 각 가정에 **근거**를 단다: "업계 평균(출처)", "보수적 추정", "1차 가설 — 검증 필요".
- **시나리오 3종**(보수/기본/공격)으로 단일 숫자에 베팅하지 않는다.
- 출처가 없으면 "가정(검증 필요)"이라고 정직하게 표기. 지어낸 정밀한 숫자(false precision) 금지.

## 1. 예산 추정 / 원가 추정

### 비용 분류
| 구분 | 예 |
|------|---|
| 개발비(일회성) | 인건비(MM × 단가), 외주, 디자인, 초기 인프라 |
| 운영비(반복) | 서버/클라우드, SaaS 구독, 결제 수수료, CS, 유지보수 |
| 마케팅비 | 광고비(CAC × 목표 고객수), 콘텐츠, 제휴 |
| 고정비 vs 변동비 | 고정: 인건비·임대 / 변동: 결제수수료·서버(사용량)·광고 |

### 추정 방법
- **Bottom-up**: 작업 단위(MM·기능)로 쪼개 합산 — 정확하나 시간 소요.
- **Top-down / 유추**: 유사 프로젝트 실적 대비 비율 — 빠르나 오차 큼.
- **3점 추정(PERT)**: 기대값 = (낙관 + 4×최빈 + 비관) / 6. 불확실성 큰 항목에 사용.
- 예비비(Contingency) 10~20%를 별도 항목으로 둔다(숨기지 않는다).

## 2. 수익성 분석

### 손익분기점 (BEP)
- **BEP(수량)** = 고정비 ÷ (단위 판매가 − 단위 변동비) = 고정비 ÷ 단위 공헌이익
- **BEP(매출액)** = 고정비 ÷ 공헌이익률
- 예) 고정비 월 1,000만, 단가 3만, 변동비 1만 → 공헌이익 2만 → BEP = 500개/월.

### ROI / 회수기간
- **ROI** = 순이익 ÷ 투자액 × 100% — 순이익은 이미 비용을 차감한 값이므로 분자에서 투자액을 또 빼지 않는다(이중 차감).
  - 분자를 총회수액(비용 차감 전)으로 잡는다면 그때는 **(총회수액 − 투자액) ÷ 투자액 × 100%**. 두 형태의 분자 정의가 다를 뿐 결과는 같아야 하며, 한 문서 안에서는 하나로 통일해 쓴다.
- **Payback Period** = 투자액 ÷ 연간 순현금흐름 (회수까지 걸리는 기간; 화폐의 시간가치 무시 — 보조지표)

## 3. 투자·사업성 평가 (화폐의 시간가치)

미래 현금흐름은 할인해서 현재가치로 본다.

### NPV (순현재가치)
- **NPV** = Σ [ CFₜ ÷ (1 + r)ᵗ ] − 초기투자
- r = 할인율(자본비용/요구수익률). **NPV > 0이면 투자 가치 있음.**
- 예) 초기 −1,000, 1~3년차 CF 각 500, r=10%:
  PV = 500/1.1 + 500/1.21 + 500/1.331 = 454.5 + 413.2 + 375.7 = 1,243.4 → NPV = **+243.4** (채택)

### IRR (내부수익률)
- NPV = 0이 되게 하는 할인율 r. **IRR > 자본비용이면 채택.**
- 직관적이나, 비정형 현금흐름(부호 여러 번 바뀜)에선 복수해 발생 가능 → NPV를 우선 신뢰.

### 민감도 분석 (Sensitivity)
- 핵심 변수(전환율·단가·이탈률·할인율)를 ±10~20% 흔들어 NPV/BEP가 어떻게 변하는지 표로 제시.
- **토네이도 차트** 개념: 결과에 가장 영향 큰 변수 순으로 정렬 → "이 사업은 무엇에 가장 민감한가"를 드러낸다.

| 변수 | -20% | 기본 | +20% | → NPV 영향 |
|------|------|------|------|-----------|
| 전환율 | | | | |
| 객단가 | | | | |
| 이탈률 | | | | |

## 4. 단위경제 (Unit Economics) — 구독/SaaS 핵심

| 지표 | 산식 | 기준 |
|------|------|------|
| ARPU | 매출 ÷ 활성 사용자 | |
| **CAC** | (마케팅+영업비) ÷ 신규 고객수 | 낮을수록 좋음 |
| **LTV** | ARPU × 매출총이익률 ÷ 월 이탈률(churn) | |
| **LTV:CAC** | LTV ÷ CAC | **≥ 3:1** 건강 |
| CAC 회수기간 | CAC ÷ (월 ARPU × 마진) | **< 12개월** 권장 |
| MRR/ARR | 월/연 반복 매출 | |
| Churn | 이탈 고객수 ÷ 기초 고객수 | 낮을수록 좋음 |

> LTV = ARPU × 마진 ÷ churn 의 직관: 월 이탈률 5%면 평균 고객수명 = 1/0.05 = 20개월. 월 공헌 3만이면 LTV = 60만.

## 5. 재무 보고서 구조

```markdown
# [프로젝트] 재무 분석 보고서

작성일: YYYY-MM-DD

## 요약 (3줄)
(투자 권고: 채택/조건부/보류 + 핵심 근거 수치)

## 가정 (Assumptions)
| 항목 | 값 | 근거/출처 |

## 비용 추정
(개발·운영·마케팅 비용 표, 예비비 포함)

## 수익 모델
(매출 산식, 가격, 예상 고객수 — 시나리오 3종)

## 수익성·투자성 분석
- BEP, ROI, 회수기간
- NPV, IRR (할인율 명시)

## 민감도 분석
(핵심 변수 ±, 토네이도)

## 단위경제 (해당 시)
(CAC, LTV, LTV:CAC, 회수기간)

## 리스크·시나리오
(보수/기본/공격, 주요 리스크와 재무 영향)

## 결론 및 권고
(의사결정 + 조건)
```

## 평범함을 넘는 기준 (재무 산출물)

- **가정 없는 단정 금지**: "연 10억 매출 예상"이 아니라 "고객 2,000명 × ARPU 4만 × 12 = 9.6억 (가정: 전환율 3%, 출처 ___)".
- **시간가치 무시 금지**: 다년 투자 판단에 단순 합산(ROI)만 쓰지 않는다. NPV/IRR로 할인.
- **단일 숫자 베팅 금지**: 시나리오 3종 + 민감도로 불확실성을 드러낸다. "무엇에 가장 민감한가"를 답한다.
- **happy path 탈출**: 이탈률 상승·CAC 상승·매출 지연 등 하방 시나리오를 반드시 포함.
- **복붙 가능 금지**: 어느 사업계획서에나 붙는 "안정적 수익 기대"는 삭제. *이 사업*의 산식·수치로 채운다.

## 6. 마케팅과의 인터페이스 — 단위경제 입력값을 공유·정합화하라 (협업)

> performance·mycerti 두 프로젝트에서 finance와 marketer가 **같은 단위경제 입력값(ARPU·마진·전환율·CAC·LTV:CAC·BEP ROAS)을 각자 따로 계산**했는데, 두 보고서가 그 값을 **맞춰보지도, 충돌을 표시하지도 않았다.** 같은 제품의 같은 숫자를 두 사람이 다르게 들고 있으면 의사결정이 깨진다.

**구체 증거:**
- performance: finance가 ARPU 7,500원·마진 78%·전환율 12%·CAC 65,000원을 **확정 가정**으로 모델링했는데, marketer 보고서는 "가격은 finance 검토 후 확정(본 문서 범위 외)"이라며 **BEP ROAS를 마진 80% 가정으로 독립 계산**(125%)했다. finance의 78%와 1:1로 맞지 않고, marketer가 finance 산출물을 참조한 흔적이 없다.
- mycerti: marketer는 "발송 마진 30% 가정 → BEP ROAS 333%"라 적고, finance는 "spread 40%·단위마진 6원"으로 모델링했다. **두 보고서가 같은 발송 마진을 다른 숫자(30% vs 40%)로 들고** 각자 결론을 냈다. 더 심각한 건, **finance가 발견한 핵심 결론("발송 종량 단독은 LTV:CAC 0.73으로 단위경제 붕괴 → 구독 병행 필수")이 marketer의 채널·캠페인 설계에 반영되지 않았다** — marketer는 "CAC를 0에 수렴"시키는 채널 전략까지만 갔고, "이 수익모델 자체가 깨진다"는 finance의 구조 진단과 만나지 않았다.

**원칙 — 단위경제는 공유 변수 1벌로 본다:**
- **ARPU·마진율·전환율·CAC·LTV:CAC·BEP ROAS는 finance와 marketer의 공유 입력값이다.** finance가 가격·마진·CAC를 확정하면 marketer는 그 값을 *그대로 인용*하고(재발명 금지), 반대로 marketer가 채널별 실측 CPC/CVR을 잡으면 finance가 CAC 가정에 *그 값을 반영*한다.
- 보고서에 **"이 값은 [상대 역할] 산출물의 ___에서 가져옴" 또는 "상대가 미확정이라 본 보고서 가정 ___로 두며, 확정 시 재계산"**을 명시한다. 같은 변수를 두 보고서가 다른 값으로 들고 있으면 **그 불일치를 표로 드러내라**(숨기면 의사결정자가 어느 숫자를 믿을지 모른다).
- **수익모델이 구조적으로 깨지는 진단(LTV:CAC<1, BEP가 현실 도달 불가)은 마케팅 전략의 전제를 무효화한다.** finance가 이런 진단을 내면 "marketer의 채널 전략은 이 구조 결함을 못 메운다"를 명시적으로 연결하라 — 단위경제가 깨진 제품은 CAC를 0으로 낮춰도 매출 천장이 인건비를 못 넘는다(mycerti 사례).
