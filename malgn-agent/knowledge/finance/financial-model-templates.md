# 재무 모델링 템플릿 (3~5년 추정)

> 추정 손익(P&L)·현금흐름(Cash Flow) 모델의 구조와 산식을 표 템플릿으로 제공한다. 산식·가정 원칙은 `financial-analysis-guide.md` 참조. 모든 셀은 가정 표에서 파생되도록 구성한다(하드코딩된 마법의 숫자 금지).

## 1. 가정 표 (모델의 단일 입력원)

모든 수치는 여기서 파생된다. 이 표만 바꾸면 전체 모델이 갱신되도록 설계.

## 3. 추정 현금흐름 (Cash Flow)

이익 ≠ 현금. 흑자도산을 막으려면 현금잔고를 추적한다.

| 항목 | Y1 | Y2 | Y3 | Y4 | Y5 |
|------|----|----|----|----|----|
| 기초 현금 | | | | | |
| (+) 영업활동 현금흐름 | | | | | |
| (−) 투자활동(설비·개발) | | | | | |
| (+/−) 재무활동(투자유치·차입) | | | | | |
| **기말 현금** | | | | | |

- **런웨이(Runway)** = 현재 현금 ÷ 월 순현금소진(burn rate). 음수 구간이 생기면 추가 자금조달 시점·규모를 명시.

## 모델링 체크리스트

- [ ] 모든 숫자가 가정 표에서 파생되는가 (하드코딩 없음)
- [ ] 매출이 고객수·ARPU·이탈률 로직으로 연결되는가
- [ ] P&L과 Cash Flow가 일치(이익→현금 조정)하는가
- [ ] 현금잔고가 음수로 빠지는 구간이 없는가 (있으면 자금조달 명시)
- [ ] NPV/IRR의 할인율이 명시되고 근거가 있는가
- [ ] 시나리오 3종 + 민감도가 있는가
- [ ] 마케팅 계획의 CAC·고객수와 모델 가정이 일관되는가 (marketer 연동)
