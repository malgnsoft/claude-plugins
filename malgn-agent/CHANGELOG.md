# 변경 이력 (Changelog)

`malgn-agent` 플러그인의 릴리스 이력입니다. 형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/)를
따르며, 버전은 [유의적 버전(SemVer)](https://semver.org/lang/ko/)을 씁니다.

플러그인 버전은 `malgn-agent/.claude-plugin/plugin.json`과 저장소 루트
`.claude-plugin/marketplace.json` 두 곳에 함께 기록됩니다. **두 값이 어긋나면
`/plugin update`가 변경을 감지하지 못하므로 반드시 같이 올립니다.**

---

## [Unreleased]

### 추가
- 플러그인 루트에 `README.md`·`LICENSE`·`CHANGELOG.md` 배치 — 설치하는 직원이
  플러그인 폴더 안에서 설치·업데이트·구성요소를 바로 확인할 수 있게 했습니다.
- `plugin.json`에 공식 규격 권장 메타데이터 `license`·`repository`·`homepage` 추가.
- GitHub Actions 워크플로 신설 — `main` push와 PR에서 플러그인 매니페스트 규격
  검증(`claude plugin validate --strict`)과 에이전트/스킬 자산 정적 검증
  (`check-assets`)을 자동 실행합니다. 마켓플레이스 매니페스트도 함께 검증해
  `plugin.json` ↔ `marketplace.json` 버전 불일치를 배포 전에 잡습니다.

### 변경
- `plugin.json`의 `description`을 규격에 맞는 짧은 소개문으로 정리했습니다.
  기존에 이 필드에 누적돼 있던 버전별 변경 이력은 이 문서로 옮겨 보존했습니다.

## [1.7.8] — 2026-08-23

### 변경
- 위임 판단이 내부 문서의 번호 체계에 묶여 있지 않도록 정리했습니다. 번호가

## [1.7.7] — 2026-08-23

### 수정
- 번들 스크립트(`bin/`)에 도달하는 실행 경로를 하나의 정본 규약으로 통일했습니다.
  추측성 경로 플레이스홀더와 맨 명령어 실행 지시를 제거하고, 회귀를 막는 린터
  게이트를 함께 넣었습니다.
- `new-project.mjs` 결함 3건 수정 — 스캐폴딩된 `check-docs`의 탐색 경로를 실물에
  맞추고, `--help`가 폴더를 만들지 않게 했습니다.
