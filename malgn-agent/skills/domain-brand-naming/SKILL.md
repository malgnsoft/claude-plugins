# 브랜드 네이밍 플레이북 (marketer / visual-designer 공용)

## 왜 이 스킬인가

`marketer`는 포지셔닝(STP·4P)을, `visual-designer`는 컬러·타이포·로고 배치를 다루지만 **이름 자체를 어떻게 짓는가**에 대한 절차가 둘 다 없다 — 완전한 공백이었다. 이 스킬은 신규 브랜드/제품/서비스명을 새로 짓거나, 이미 나온 후보 이름을 검증할 때 쓰는 7단계 절차다.

## 착수 전 확인

- 포지셔닝 스테이트먼트(marketer 산출물, `docs/marketing/`) 또는 PRD의 제품 방향이 먼저 있어야 한다 — 이름은 포지셔닝의 표현이지 포지셔닝보다 앞설 수 없다. 없으면 먼저 marketer에게 포지셔닝 확정을 요청한다.
- 대상 레벨을 명확히 한다: 신규 브랜드명 / 신규 제품·서비스명 / 신규 기능명(대형 기능만) 중 어디인지.

## 1. 문제 정의

- 왜 새 이름이 필요한가(신규 런칭 / 리브랜딩 / 기존명 문제) 1문장으로 명시.
- 제약조건을 슬롯으로 채운다: 언어 범위(한글만/영문 병기/글로벌), 금칙어(경쟁사 유사 표기·기존 상표 회피), 길이 상한(음절 수), 필수 포함 의미(있다면 없다면 "없음"도 명시).
- **실패 시나리오**: 제약 없이 바로 후보부터 만들면 상표·도메인 문제로 뒤늦게 전량 폐기되는 재작업이 생긴다 — 제약을 먼저 고정하는 것이 재작업 방지의 핵심이다.

## 2. 시장·경쟁 조사

- 직접 경쟁사 5개 이상 + 인접 카테고리 3개 이상의 실제 제품/브랜드명을 수집한다(WebSearch, 출처 명시 — Skill `domain-external-research-and-citation` 참조).
- 각 경쟁사명의 네이밍 패턴을 분류한다: 서술형(기능을 그대로 말함) / 조어형(신조어) / 은유형(비유) / 이니셜형. 표로 정리해 "이 시장의 관행"과 "우리가 차별화할 지점"을 구분한다.
- 국내는 특허청 키프리스(kipris.or.kr), 글로벌은 WIPO Global Brand Database로 최소 1차 스크리닝을 남긴다(법적 확정이 아니라 1차 필터임을 명시 — 법무 검토는 별도).
- 도메인(.com/.co.kr)과 주요 SNS 핸들 가용성도 이 단계에서 함께 확인한다.

## 3. 네이밍 원칙 수립

열린 지시("좋은 이름을 고른다") 대신 슬롯 형식으로 원칙을 고정한다:

| 기준 | 판정 질문 |
|---|---|
| 발음성 | 처음 듣고 3초 내 따라 말할 수 있는가? |
| 의미 연상 | 포지셔닝 스테이트먼트의 핵심 차별점과 즉시 연결되는가? |
| 차별성 | 2단계 경쟁사 목록과 발음·표기가 겹치지 않는가? |
| 확장성 | 서브 브랜드·라인업이 늘어나도 이름이 의미를 좁히지 않는가? |
| 등록 가능성 | 2단계 상표 1차 스크리닝을 통과했는가? |
| 디지털 가용성 | 도메인/SNS 핸들을 확보(또는 합리적 변형으로 확보) 가능한가? |

## 4. 후보 전개

- 최소 15개 이상 발산한다(1차 브레인스토밍). 네이밍 기법 3종 이상을 섞는다: 조어(합성·축약), 은유(연상), 서술+변형(기존 단어 철자 변형).
- 15개를 3장 원칙표 기준으로 1차 스크리닝해 5~8개로 좁힌다. **탈락 사유를 후보마다 1줄씩 기록**한다 — 시점을 고정해두지 않으면 나중에 "이미 검토했다"가 사후 합리화로 흐려진다.

## 5. 다관점 교차검증

- **marketer 관점**: 포지셔닝 부합, 타겟 발음 편의, 채널(SEO 키워드 충돌 여부).
- **visual-designer 관점**: 로고/워드마크로 시각화했을 때 균형(음절 수·자간), 다국어 병기 시 어색함.
- **발산형 관점(필수 1명 이상)**: 위 두 관점과 다른 시각으로 본다 — 예: 잠재고객 역할극("이 이름을 검색창에 입력한다면?"), 또는 부정적 연상(오독·비속어 유사음) 전담 점검. Skill `reviewer-persona-panel-standard`의 "발산형 페르소나 최소 1명" 원칙을 그대로 차용한다.
- 5~8개 후보 각각에 3관점 점수(상/중/하)를 매긴 교차검증표를 산출물에 남긴다.

## 6. 최종 선정

- 교차검증표에서 상위 2~3개로 좁혀 최종 비교표(장점·단점·리스크)를 작성한다.
- 최종 1개를 선정하고 선정 근거 3줄 이상(포지셔닝 연결·차별성·리스크 감당 방안)을 남긴다 — "느낌이 좋아서" 같은 근거 없는 단정은 불가.

## 7. 실행 체크리스트 (확정 후)

- [ ] 최종명 상표 정식 출원 절차 안내(법무 소관 — marketer/visual-designer는 안내까지, 실제 출원은 담당자 승인 후 진행)
- [ ] 도메인/SNS 핸들 확보는 실제 결제·등록이 따르는 집행 행위이므로 **사람 승인 후 진행**(marketer.md의 "집행 승인 게이트"와 동일 원칙 — 계획까지만 산출, 집행은 승인 후)
- [ ] 로고/워드마크 제작은 visual-designer가 이어받는다(`docs/design/brand.md`)
- [ ] 탈락 후보 목록과 탈락 사유를 산출물에 남긴다(재검토 방지)

## 산출물

- `docs/design/brand-naming.md` — 1~7단계 전 과정(문제정의~최종선정) + 교차검증표 + 탈락 사유
- marketer/visual-designer 공동 작성 시 각자 담당 관점 파트에 담당자를 표기한다.

## evaluator 판정 기준 (참고)

- 후보가 실제로 15개 이상 발산됐는가(목록·표로 확인 가능)
- 탈락 사유가 후보마다 1줄 이상 기록됐는가(사후 합리화가 아니라 시점 고정 기록인가)
- 다관점 교차검증표에 발산형 관점이 최소 1개 포함됐는가
- 최종 선정 근거가 느낌이 아니라 3장 원칙표 대조로 서술됐는가
