## 요구사항 원문

```
발주처: (주)한빛설비관리 — 전국 산업단지 기계설비 정기점검 대행업체
현장 점검원 40명, 사무 관리자 6명, 고객사 담당자 약 300명이 쓴다.

- 점검원은 태블릿을 들고 현장에 나가 설비별 체크리스트를 채우고 사진을 찍는다.
- 산업단지 지하 기계실·플랜트 내부는 LTE가 아예 안 잡히는 구간이 많다.
  점검 도중 몇 시간씩 오프라인 상태가 이어진다.
- 점검이 끝나면 결과가 고객사 담당자에게 보고서로 나가야 한다.
- 관리자는 어느 점검이 지연되는지, 어떤 설비가 반복 불합격인지 보고 싶어 한다.
- 고객사는 자기 회사 점검 결과만 볼 수 있어야 한다. 다른 고객사 데이터가 보이면 계약 위반이다.
- 법정 정기점검이라 점검 기록은 5년간 위변조 없이 보관해야 한다.
```

## PRD

```
# 현장 설비점검 관리 SaaS — PRD

## 1. 문제
점검원이 지하 기계실에서 오프라인으로 점검한 결과를, 사무실 복귀 후 수기로 옮겨
적으면서 누락·오기입이 발생한다. 관리자는 점검 진행 상황을 실시간으로 알 수 없다.

## 2. 목표
- 오프라인 상태에서도 점검이 끊기지 않고, 통신이 복구되면 자동으로 서버에 반영된다.
- 점검 완료 즉시 고객사에 보고서가 나간다.
- 고객사 간 데이터가 절대 섞이지 않는다.

## 3. 경쟁사 비교

| 항목 | 경쟁사 A (세이프체크) | 경쟁사 B (인스펙션원) | 우리 |
|---|---|---|---|
| 오프라인 점검 | 미지원 — 통신 되는 곳에서만 입력 | 로컬 임시저장만, 복귀 후 사람이 수동 업로드 | **오프라인 큐잉 + 통신 복구 시 자동 동기화, 충돌은 서버 규칙으로 자동 해결** |
| 사진 첨부 | 장당 수동 업로드 | 지원하나 오프라인 시 유실 | **오프라인 촬영분까지 큐에 담아 재개 가능한 분할 업로드** |
| 보고서 발송 | 관리자가 수동 발송 | 수동 발송 | **점검 확정 시 자동 발송(발송 실패 시 재시도)** |
| 고객사 분리 | 계정 분리(테넌트 개념 없음) | 테넌트 있음 | 테넌트 있음 |
| 가격 | 사용자당 월 3만원 | 사용자당 월 2.5만원 | 사용자당 월 2.2만원 |

## 4. 기능 요구사항
- FR-01 점검 일정 배정(관리자 → 점검원)
- FR-02 태블릿 오프라인 점검 입력 + 사진 촬영
- FR-03 통신 복구 시 자동 동기화(중복 전송·부분 실패 대응 필요)
- FR-04 점검 확정 → 보고서 생성 → 고객사 담당자에게 자동 발송
- FR-05 관리자 대시보드(지연 점검, 반복 불합격 설비)
- FR-06 고객사 포털(자사 점검 결과 조회 전용)

## 5. 비기능 요구사항
- NFR-01 동시 점검 진행 200건, 동기화 요청 피크 시 분당 2,000건
- NFR-02 점검 기록 5년 보관, 확정 후 변경 이력 추적 가능
- NFR-03 테넌트(고객사) 간 데이터 격리
- NFR-04 사진 1건 최대 10MB, 점검 1건당 최대 30장
```
