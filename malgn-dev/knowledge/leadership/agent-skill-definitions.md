# 에이전트별 스킬 정의 및 점수 체계

작성일: 2026-07-09
버전: 1.0
참조: malgnai(사내 전용 프로젝트)의 `bin/skill-definitions.js` — 이 플러그인에는 미포함, 원본 소스 위치 참고용

---

## 점수 체계 개요

### 스킬 점수 (80%)
- 각 에이전트별 핵심 스킬 5~8개, 합산 100점
- 측정: `node bin/sync-agents.js` — MD 키워드 매칭으로 1~5점 산출
- 환산: 스킬 원점수 = Σ(skill_level × 배점/5)
- **주의**: 키워드 점수는 보조 지표. 실제 역량은 산출물 진단(모드 7)으로 판단.

### 경험 점수 (20%)
- 프로젝트 참여·재작업 없음·리뷰 통과 등으로 적립
- 최대 100점
- 적립/차감은 trainer가 경험 이력 섹션에 기록

### 최종 점수 공식
```
최종점수 = 스킬점수 × 0.8 + 경험점수 × 0.2
```
