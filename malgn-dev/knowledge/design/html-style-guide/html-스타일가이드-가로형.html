06 · Dark Shell & Export

다크 셸 .slide.dark / .pivot · PDF 출력 체크리스트

표지·클로징 슬라이드는 .slide.dark에 .grad/.grid-tex/.deco를 겹쳐 쓰고, 가운데 강조 문구만 필요하면 .pivot을 추가한다.

PDF 출력 전 체크리스트
  • · 슬라이드마다 <section class="slide">로 감쌌는가? (한 섹션 = 한 장)
  • · @page{size:1280px 720px;margin:0}와 @media print 블록이 그대로 있는가?
  • · 인쇄 시 대상: PDF 저장 · 여백: 없음 · 배경 그래픽 인쇄: 켜짐인가? (꺼지면 배경·그라디언트 소실)
  • · 자동화가 필요하면 page.pdf({width:'1280px',height:'720px',printBackground:true})를 쓴다.

새 슬라이드 문서를 만들 때는 이 파일을 통째로 복사한 뒤 <section class="slide">를 필요한 장 수만큼 반복하면 된다 — 매 슬라이드는 ① s-head(제목) → ② body(본문 컴포넌트) → ③ s-foot(로고/푸터) 순으로 배치한다.
