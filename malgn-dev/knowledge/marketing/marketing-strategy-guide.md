# 마케팅 전략 가이드

> 마케팅을 "할 일 나열"에서 **검증 가능한 가설·지표로 묶인 전략**으로 끌어올린다. 모든 캠페인은 "누구에게(STP) → 무엇을(4P/메시지) → 어디서(채널) → 얼마에(예산·CPA) → 어떻게 측정(KPI)"이 한 줄로 연결돼야 한다. 채널별 실행 구조·단가·연동·집행 승인 게이트는 `digital-ad-channels.md` 참조.

## 1. STP — 시장 세분화·타겟팅·포지셔닝

전략의 출발점. "모두에게 팔겠다"는 평범함의 신호다.

| 단계 | 핵심 질문 | 산출물 |
|------|----------|--------|
| Segmentation | 시장을 어떤 축으로 쪼갤 것인가 (인구통계·행동·니즈·산업/규모) | 세그먼트 표 |
| Targeting | 어느 세그먼트가 가장 매력적인가 (규모 × 접근성 × 수익성 × 적합도) | 우선 타겟 1~2개 + 근거 |
| Positioning | 타겟의 머릿속에서 우리는 무엇으로 기억되는가 | 포지셔닝 스테이트먼트 |

**포지셔닝 스테이트먼트 템플릿**:
> [타겟]에게 [우리 제품]은 [경쟁 대안] 대비 [핵심 차별점]을 제공하는 [카테고리]다. 왜냐하면 [근거]이기 때문이다.

예: "코칭회사를 운영하는 중소 HRD 담당자에게 맑은AI는 일반 LMS 대비 *AI 코칭 엔진*을 제공하는 코칭 운영 플랫폼이다. 왜냐하면 일정관리를 넘어 코칭 품질 자체를 데이터로 관리하기 때문이다."

## 2. 4P / 마케팅 믹스

| P | 점검 항목 |
|---|----------|
| Product | 핵심 가치 제안(USP), 기능 우선순위, 차별점 |
| Price | 가격 모델(구독/단건/프리미엄), 가격 포지셔닝, 할인 정책 |
| Place | 판매·전달 채널(자사몰·스마트스토어·앱스토어·B2B 직판) |
| Promotion | 광고·콘텐츠·PR·제휴·이벤트 채널 믹스 |

> 디지털·구독 제품은 4P를 7P(+People/Process/Physical Evidence)로 확장하거나 4C(Customer value/Cost/Convenience/Communication)로 고객 관점 전환을 권장.

## 3. 퍼널 — AARRR (해적 지표)

캠페인은 퍼널 단계 중 **어느 구간을 푸는지** 명시해야 한다.

| 단계 | 정의 | 대표 지표 |
|------|------|----------|
| **Acquisition** | 어떻게 유입되는가 | 방문수, CPC, 노출/클릭(CTR) |
| **Activation** | 첫 가치 경험(Aha moment) | 가입률, 온보딩 완료율 |
| **Retention** | 다시 오는가 | DAU/MAU, 리텐션 곡선, 이탈률 |
| **Revenue** | 어떻게 돈이 되는가 | 전환율, ARPU, LTV |
| **Referral** | 추천하는가 | NPS, 바이럴 계수(K) |

**진단 원칙**: 퍼널에서 **가장 새는 단계**를 먼저 찾는다. 유입이 충분한데 전환이 낮으면 광고비를 늘리지 말고 Activation/Revenue를 고친다. (광고로 깨진 퍼널을 메우는 것이 가장 비싼 실수)

## 4. 채널 믹스 설계

PESO 모델로 채널을 분류해 균형을 본다.

| 유형 | 채널 예 | 특성 |
|------|--------|------|
| **Paid** | 구글/네이버 검색광고, 메타·인스타 광고 | 즉효성, 끄면 멈춤, CPC 상승 리스크 |
| **Earned** | 언론 보도, 리뷰, 입소문 | 신뢰 높음, 통제 어려움 |
| **Shared** | SNS 공유, 커뮤니티 | 바이럴 잠재력 |
| **Owned** | 블로그/SEO, 뉴스레터, 자사 앱 | 자산 축적, 장기 복리 효과 |

**원칙**: Paid는 즉시 트래픽을 사지만 멈추면 0이 된다. Owned(SEO·콘텐츠)는 느리지만 누적 자산이다. **단기 Paid로 검증 → 효과 본 메시지를 Owned로 자산화**하는 구조를 권장. 단일 채널 올인 금지(채널 정책·단가 변동 리스크).

## 5. 캠페인 기획 절차

```
1. 목표 정의 (SMART) — "3개월 내 무료가입 월 500건, CPA 1.5만원 이하"
2. 타겟·메시지 — STP 기반, 퍼널 단계 명시
3. 채널·예산 배분 — 채널별 예상 CPC/CPA로 예산 시뮬레이션 (digital-ad-channels.md)
4. 크리에이티브·랜딩 — 메시지-광고-랜딩페이지 일관성 (메시지 매치)
5. 측정 설계 — KPI·전환 이벤트·UTM·대시보드 정의 (사전에!)
6. 실행 계획서 작성 → 사람 승인 게이트 → (승인 후) 집행
7. 모니터링·최적화 — 주간 리뷰, A/B 테스트, 예산 리밸런싱
```

**캠페인 1장 요약(One-pager) 템플릿**:
| 항목 | 내용 |
|------|------|
| 캠페인명 / 기간 | |
| 목표(SMART) | |
| 타겟 / 퍼널 단계 | |
| 핵심 메시지 | |
| 채널·예산 배분 | 채널별 표 |
| 예상 성과 | 노출→클릭→전환 시뮬레이션 |
| KPI / 손익 기준 | 목표 CPA, ROAS |
| 측정 방법 | 전환 이벤트, UTM 규칙 |
| 승인 필요 사항 | (집행 전 사람 승인 항목) |

## 6. KPI·지표 정의와 산식

| 지표 | 산식 | 의미 |
|------|------|------|
| CPC | 광고비 ÷ 클릭수 | 클릭당 비용 |
| CTR | 클릭수 ÷ 노출수 | 광고 매력도 |
| CVR(전환율) | 전환수 ÷ 클릭수 | 랜딩·오퍼 설득력 |
| CPA / CAC | 광고비 ÷ 전환수(신규고객수) | 고객 1명 획득 비용 |
| ROAS | (광고 기여 매출 ÷ 광고비) × 100% | 광고비 1원당 매출 |
| ROI | (이익 − 투자) ÷ 투자 | 이익 기준 수익률 |
| LTV | ARPU × 평균 고객수명(또는 = 평균 객단가 × 구매빈도 × 유지기간) | 고객 생애가치 |
| LTV:CAC | LTV ÷ CAC | 건강성 기준 **3:1 이상** 권장 |

**ROAS 손익분기 산식**: 손익분기 ROAS = 1 ÷ 매출총이익률. 예) 마진 40% → BEP ROAS = 1/0.4 = **250%**. ROAS가 250% 미만이면 광고할수록 손해.

> 벤치마크(2025~2026, 출처 명시 필수): B2B SaaS 구글 평균 CPC 약 $8.86(전년比 +29%), 평균 CVR 약 2.9%, CPA 약 $130+, SaaS 권장 LTV:CAC 3:1. 한국 네이버 검색광고 CPC 업종별 평균 약 100~300원대(경쟁 키워드는 수천 원). **이 수치는 시점·업종 의존이므로 작업 시 WebSearch로 재확인하고 출처를 단다.** (출처: Powered by Search, Lever Digital, 소중함인사이트 — `digital-ad-channels.md` 출처표 참조)

| 채널 | 예산 | 전환 | CPA | ROAS | 판정 |

## 평범함을 넘는 기준 (마케팅 산출물)

- **복붙 가능 금지**: "SNS를 활용해 인지도를 높인다" 같은 문장은 어느 회사에나 붙는다 → 삭제. *이 제품·이 타겟*에만 해당하는 채널·메시지·수치를 쓴다.
- **수치엔 근거·산식**: "ROAS 높임"이 아니라 "현재 ROAS 180% → 마진 40% 기준 BEP 250% 미달이므로 CVR 2.9%→4% 개선 또는 CPC 절감 필요". 모든 목표치에 산식과 출처.
- **발산 후 수렴**: 채널 3~4개 후보를 비교 검토(발산)한 뒤 우선순위와 이유를 정함(수렴). 처음부터 한 채널만 적으면 검토가 빈약하다는 신호.
- **집행 경계 명시**: 산출물은 *계획서*다. 실제 예산 지출·캠페인 ON은 "사람 승인 게이트" 뒤에 둔다 — 보고서에 승인 필요 항목을 별도 표기.

## 8. 단위경제 입력값은 finance와 공유한다 — 따로 발명하지 마라 (협업)

> 신설 사유 (2026-06-20, 모드 7 진단): performance·mycerti 두 보고서에서 marketer가 **마진율·BEP ROAS·전환율 같은 단위경제 수치를 finance와 따로 계산**했고, finance의 핵심 재무 진단을 채널 전략에 반영하지 못했다. 마케팅 계획의 경제성은 finance 모델 위에 서야 한다.

**구체 증거:**
- performance: marketer가 "마진율 80% 가정 → BEP ROAS ≈ 125%"를 독립 계산했는데, 같은 제품을 finance는 **마진 78%·ARPU 7,500원·CAC 65,000원**으로 확정 모델링하고 있었다. marketer는 "가격은 finance 범위 외"라며 넘겼지만, 정작 **finance가 이미 낸 마진·CAC 숫자를 인용해 BEP ROAS·목표 CPL을 정합화하지 않았다.** 결과적으로 두 문서의 마진 숫자가 미세하게 어긋난 채 따로 논다.
- mycerti: marketer는 "발송 마진 30% → BEP ROAS 333%, CAC를 0에 수렴시켜라"까지 갔는데, finance는 한발 더 들어가 **"발송 종량 단독은 LTV:CAC 0.73 — 수익모델 자체가 깨진다, 구독 병행 필수"**라는 구조 진단을 냈다. marketer의 채널 전략(인스톨드 베이스·레퍼럴로 CAC↓)은 옳지만, **CAC를 낮춰도 단위마진이 너무 작아 매출이 인건비를 못 넘는다는 finance의 결론과 만나지 않았다.** "CAC를 0으로"는 분모만 고친 것이고, 분자(기관당 매출 천장)가 깨졌다는 진단은 채널 전략으로 못 푼다.

**원칙:**
- **마진율·ARPU·CAC·BEP ROAS·LTV:CAC는 finance와의 공유 변수다.** finance 모델이 있으면 그 값을 *그대로 인용*하고(재발명 금지), 출처를 "finance 보고서 §___"로 단다. finance가 미확정이면 본인 가정을 쓰되 "finance 확정 시 재계산" 단서를 붙이고, 확정 후 *반드시 맞춰본다*.
- **채널 전략을 짜기 전에 finance의 단위경제 결론을 먼저 읽어라.** LTV:CAC<1이거나 BEP ROAS가 비현실적으로 높으면, 그건 "더 싼 채널을 찾을" 문제가 아니라 **수익모델/가격 구조의 문제**다 — 이 경우 채널 최적화보다 "이 제품은 가격/수익모델을 바꿔야 광고가 성립한다"를 보고서에 명시하는 게 정직하고 유용하다.
- 마진이 박한 종량 과금 제품에서 **"BEP ROAS = 1÷마진율"이 수백 %로 나오면**, 단기 광고 회수가 구조적으로 불가능하다는 신호다. 이때 LTV를 "1회 거래"가 아니라 "누적·락인·업셀"로 재정의하는 것까지는 옳으나(mycerti에서 잘함), **그 재정의가 finance의 BEP/단위경제 결론과 같은 숫자 위에 서는지** 반드시 교차 확인하라.
