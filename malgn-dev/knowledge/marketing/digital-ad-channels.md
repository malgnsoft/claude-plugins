# 디지털 광고 채널 가이드 (구글·네이버)

> 채널의 **구조·과금방식·연동(API/태그)·실행 계획서 템플릿·집행 승인 게이트**를 정리한다. 전략·퍼널·KPI 정의는 `marketing-strategy-guide.md` 참조. 단가·정책은 시점 의존이므로 작업 시 WebSearch로 재확인하고 출처를 단다.

## 0. 집행 승인 게이트 (가장 중요 — 반드시 지킬 경계)

marketer 에이전트는 **실제 광고 집행을 임의로 하지 않는다.** 산출물은 *계획서·연동 가이드·시뮬레이션*까지이며, 아래는 반드시 사람 승인 뒤에 둔다.

| 행위 | 에이전트 가능 | 사람 승인 필요 |
|------|:---:|:---:|
| 채널 정책·단가·트렌드 조사 (WebSearch/WebFetch) | O | |
| 키워드·타겟·예산 **계획서** 작성 | O | |
| 예상 비용·성과 **시뮬레이션** | O | |
| 측정 설계(UTM 규칙·전환 이벤트 정의) 문서화 | O | |
| 광고 계정 생성·연결, 결제수단 등록 | | O |
| 캠페인 **ON**, 예산 **지출**, 입찰가 변경 | | O |
| 자동 입찰·예산 자동조정 설정 활성화 | | O |

> 계획서 말미에 **"집행 승인 필요 항목"** 표를 반드시 붙이고, 각 항목의 예상 지출 상한을 명시한다. "근거 없이 집행해도 된다"는 가정 금지.

## 1. Google Ads

### 캠페인 유형
| 유형 | 용도 | 과금 |
|------|------|------|
| 검색(Search) | 구매의도 키워드 대응 | CPC |
| 디스플레이(GDN) | 인지도·리타게팅 | CPM/CPC |
| 동영상(YouTube) | 브랜딩·도달 | CPV/CPM |
| 쇼핑(Shopping/PMax) | 이커머스 상품 노출 | CPC/전환기반 |
| 실적 최대화(Performance Max) | 전 채널 자동 최적화 | 전환/전환가치 기반 |

### 과금·입찰
- 기본 CPC(클릭당), 입찰 전략: 수동 CPC, 전환수 최대화(tCPA), 전환가치 최대화(tROAS).
- **품질평가점수(Quality Score)** = 예상 CTR × 광고 관련성 × 랜딩페이지 경험. 높으면 같은 순위를 더 싸게 산다.

### 측정·연동 (GA4 + Google Ads)
- **GA4**: 이벤트 기반 측정. `purchase`, `sign_up`, `generate_lead` 등 전환 이벤트 정의 → Google Ads로 가져오기(import).
- **연동 흐름**: GA4 속성 ↔ Google Ads 계정 연결 → 전환 이벤트를 Ads 전환으로 등록 → 입찰 최적화에 사용.
- **태그**: Google Tag(gtag.js) 또는 Google Tag Manager(GTM)로 사이트에 설치. Enhanced Conversions(해시된 1st-party 데이터)로 정확도 보강.
- **UTM**: `utm_source/medium/campaign/term/content`로 유입 출처 추적. 채널 간 일관 규칙 필수.

## 2. SEO / 콘텐츠 마케팅 (Owned)

- **3축**: 기술적 SEO(크롤링·색인·속도·모바일·구조화 데이터), 온페이지(제목·메타·헤딩·내부링크·E-E-A-T), 오프페이지(백링크·언급).
- **키워드 전략**: 검색의도(정보형/거래형/탐색형) 분류 → 거래형은 Paid, 정보형은 콘텐츠로 커버. 롱테일로 경쟁 낮은 진입점 확보.
- **측정**: Google Search Console(노출·클릭·평균순위), GA4 오가닉 세션. SEO는 누적 자산 — 효과는 느리지만 복리.
- **AI 검색 시대 보강**: 생성형 검색(AI Overviews/SGE) 노출을 위해 명확한 질문-답변 구조, 출처·전문성 신호 강화.

## 3. 네이버 (국내 핵심)

### 네이버 검색광고
| 상품 | 노출 위치 | 과금 |
|------|----------|------|
| 파워링크 | 통합검색 상단/하단 | CPC |
| 쇼핑검색광고 | 네이버쇼핑 상위 | CPC |
| 파워콘텐츠 | 검색결과 콘텐츠 영역 | CPC |
| 브랜드검색 | 브랜드 키워드 상단 점유 | 기간/정액 |
| 플레이스광고 | 지역 검색(지도) | CPC |

- CPC 경매 방식. 업종별 평균 CPC 약 100~300원대, 경쟁 키워드는 수천 원까지(시점·업종 의존 — WebSearch 재확인).
- **검색광고 API**: 네이버 검색광고 API로 키워드 조회·통계·캠페인 관리 자동화 가능(조회·시뮬레이션 용도까지만; 집행 변경은 승인 게이트).

### 스마트스토어 (Place/커머스)
- 판매 수수료 약 3.74% 수준(+ 결제·연동 수수료, 카테고리별 차이 — 재확인 필수).
- 검색 노출 로직(상품명·태그·리뷰·판매실적) 최적화가 광고만큼 중요.

### 블로그 / 플레이스 (Earned·Owned)
- 블로그: 정보형 콘텐츠로 검색 유입·신뢰 구축(C-Rank·DIA 로직). 체험단·인플루언서 협업.
- 플레이스: 오프라인·지역 비즈니스의 지도 노출·리뷰 관리.

### 측정·연동
- **네이버 프리미엄 로그분석** / 전환추적 스크립트를 사이트에 설치 → 검색광고 전환 측정.
- GA4와 병행 시 UTM으로 네이버 유입을 분리 집계.
