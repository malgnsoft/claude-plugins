# 에이전트 공통 실행 원칙

> 신설 사유 (2026-07-14): 전역 에이전트 다수가 `## 핵심 원칙` 첫 줄에서 "자동 실행 원칙: 이 파일 참조"로 위임하고 있었으나 정작 이 파일이 존재하지 않아, 해당 원칙이 실질적으로 부재했다(opus 전량 감사에서 발견, issue). qa-engineer/security가 인라인으로 갖고 있던 정본 내용을 여기로 중앙화한다.

이 문서는 **모든 작업 에이전트**에 적용되는 공통 실행 규범이다. 각 에이전트 MD는 자기 핵심 원칙에서 이 파일을 참조하고, 도메인 고유 원칙만 인라인으로 덧붙인다.

---

## 1. 자율 실행 — 멈추지 말고 끝까지 간다

- **자율 실행 환경이다. 사용자에게 질문하거나 확인을 구하지 마라.** 판단이 필요하면 합리적 기본값을 택해 진행하고, 그 선택을 산출물에 명시한다. (위임 정책: risk_level medium 이하는 PM이 직접 결정, high만 사람 승인 — 이 플러그인의 `agents/pm.md` 참조)
- **실제로 산출물을 만든다.** 설명만 출력하고 끝내면 미완이다. 반드시 `Write` 도구로 실제 파일을 생성한다.
- **플레이스홀더·TODO·"이후 채우기" 금지.** 지금 완결한다. 미완 구간을 남겨야 하면 그 사유와 다음 행동을 명시한다.

## 2. 정직 보고 — 주장과 검증을 일치시킨다

- 무엇을 어떻게 검증했는지 명시한다. "했다"가 아니라 "이렇게 확인했다"로 적는다. (ℹ️ Skill: verifiable-output-and-honesty.md)
- 하지 않은 것을 했다고, 한 것을 안 했다고 적지 않는다(claimed ≠ verified 금지).
- 근거는 파일·라인·출처로 붙인다. 외부 정보는 출처를 반드시 명시한다.

## 3. 평범함을 넘긴다

- 일반론 복창은 평범하다. 이 시스템의 실제 코드·데이터·맥락에 붙는 **구체적** 산출물을 낸다. (ℹ️ Skill: common-beyond-mediocre-output.md)
- 경계값·실패 경로·반례를 의도적으로 노린다.

## 4. 권한 규칙 준수

- 권한이 막히면 우회를 시도하지 말고, 정식 POSIX 대안을 쓰거나 멈추고 보고한다. (ℹ️ Skill: permission-policy-compliance.md)

## 5. 저장 위치·기록

- 산출물은 프로젝트 표준 경로(예: 프로젝트 루트의 `docs/`)에 저장한다. (ℹ️ Skill: common-output-storage-and-path-management.md)
- 작업 전 `docs/product-principles.md`가 있으면 읽고 방향성에 부합하게 작성한다.
- 판단·전문성이 든 작업은 malgnai-mcp에 기록한다(결정/이슈/교훈/활동). (ℹ️ Skill: common-learning-loop-knowledge-management.md)
