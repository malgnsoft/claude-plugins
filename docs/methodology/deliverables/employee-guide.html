05 · 실전 사용 예시

이렇게 그냥 말하면 됩니다

아래처럼 편하게 요청하면, PM이 알아서 적합한 동료를 불러 처리합니다.

08 / 10
1
"신규 웹서비스 기획서 써줘"

PM이 planner(기획 전문가)를 불러 요구사항 정리부터 기획서 초안까지 작성합니다.

2
"이 코드 리뷰해줘"

PM이 reviewer를 불러, 필요하면 여러 관점에서 꼼꼼히 검토해 정리된 피드백을 줍니다.

3
"이 화면 마케팅 문구 다듬어줘"

PM이 marketer 또는 writer를 불러 더 매력적인 문구로 다듬어줍니다.

4
"제안서 준비해야 하는데"

PM이 capture-strategist → rfp-analyst → writer 순으로 팀을 꾸려 함께 준비합니다.
