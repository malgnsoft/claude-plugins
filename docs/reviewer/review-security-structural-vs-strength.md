## 잘 된 점 (유지할 패턴)

- **지시를 강화하면서 비용을 늘리지 않은 자리가 있다.** `architect.md`는 대조 의무를 새로 부과했는데도 −4 B다(16,271 → 16,267). "성능을 올리려면 반드시 커진다"가 아님을 보여준다.
