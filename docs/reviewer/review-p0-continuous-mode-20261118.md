- 크리티컬을 새 목록으로 만들지 않고 기존 ④⑤를 확장해 지목한 구조. 정본이 하나로 남는다.
- autopilot에서 대기 건을 "세운 그 자리에서" `issue_record`와 STATUS에 남기게 한 것(:32). 반환이 늦어져도 최상위 세션의 정기 보고가 기록으로 대기 건을 볼 수 있다.
- 구 정지 문구 사본(director·relay·philosophy)을 같은 커밋에서 정정했다(grep 0건). 변경이력 원칙을 지켰다.
- 커밋 자율의 스테이징 규율(경로 지정, `git add -A` 금지, §3 흡수 허용 미적용 명시)이 git-safety 스킬보다 엄격한 방향으로만 갈린다.
- 제품 본문 금지어(이력·id·mille) 0건. 스킵 표기와 미커밋 수 같은 작은 항목도 1~2줄로 절제했다.
