- **계약의 양 끝을 모두 막았다.** C-1은 autopilot(쓰는 쪽)과 호출자(확인하는 쪽) 양방향으로 닫혔고, 확인 기준이 "존재"에서 "검색으로 걸림"이라는 **실측 가능한 형태**로 바뀌었다.
- **요청받지 않은 Minor·Nit 5건(m-1~m-4, n-2)까지 같은 커밋에서 닫았다** — 이 저장소가 반복적으로 겪은 "다음 라운드에 새 결함처럼 재등장" 패턴을 차단한 처리다.
- **m-1 해소가 1차 개선안보다 강하다** — 문면을 맞추는 데 그치지 않고 "되돌리면 상위 루프가 사람 판단을 대신하려 든다"는 이유까지 넣어, 규칙이 상황에 따라 흘려지지 않게 했다.
- 추가 텍스트에 날짜·식별자·이력 서술 0건(diff 전체 grep 확인) — 제품 본문 저작 규율 유지.

- **실행 검증 없음** — 1차와 동일. director/autopilot을 실제로 스폰하지 않았고, 깊이 판정은 공식문서 원문 + `tools:` 전수에 근거한다. 이번에 새로 실행한 것은 `pnpm run check-assets`·`pnpm run check-docs` 두 정적검사뿐이며 그 출력은 본문에 인용했다.

- **발산형 페르소나 미투입** — 축소 모드 판정에 따름(사유는 위 재사용 판정 표). 1차 보고서의 "구조적 제언 (Rethink)" 3건이 현행으로 유효하다.
