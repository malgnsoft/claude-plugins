01 · 설치

명령 두 줄이면 설치가 끝납니다

클로드코드를 실행한 뒤, 아래 두 명령을 순서대로 입력하세요.

02 / 08
클로드코드 입력창COMMAND
# ① 마켓플레이스 등록
claude plugin marketplace add malgnsoft/claude-plugins

# ② 플러그인 설치
claude plugin install malgn-agent@malgnsoft-plugins
설치가 끝나면 클로드코드를 재시작해야 적용됩니다. 재시작 전까지는 에이전트가 보이지 않는 것이 정상입니다.

02 · 설치 확인

디바이스 토큰 칸은 비워두세요

설치 중 화면 하나만 조심하면 나머지는 순서대로 넘기면 됩니다.

03 / 08
1
토큰 입력 화면이 나오면

아무것도 입력하지 말고 Enter만 누릅니다. 정상 설치에서는 비워두는 것이 맞습니다.

2
클로드코드를 재시작

설치·업데이트 모두 재시작해야 실제로 적용됩니다.

3
claude plugin list로 확인

목록에 malgn-agent가 보이고 활성화되어 있으면 완료입니다.

왜 비워두나요?
이 항목은 사내망 방화벽 등으로 로그인 창이 아예 열리지 않는 예외 상황을 위한 것입니다. 값을 채워 넣어도 자동으로 쓰이지 않습니다. 정상적인 로그인은 나중에 브라우저 창으로 따로 이뤄집니다. 확실하지 않으면 임의로 값을 넣지 말고 dev@malgnsoft.com으로 문의하세요.

03 · 기본 사용법

따로 배울 명령이 없습니다 —
그냥 PM에게 하고 싶은 말을 거세요

"이 화면 만들어줘", "이거 검토해줘"처럼 일상적인 말로 요청하면, 총괄 에이전트 PM이 요청을 분석해서 필요한 전문 에이전트를 알아서 불러 팀을 꾸립니다.

step 1
내 요청
평소 말투로 편하게
→
step 2
PM
필요한 전문 에이전트 자동 호출
→
step 3
결과물
검증까지 마친 산출물

특정 에이전트를 직접 부르고 싶다면 "architect한테 설계 검토 부탁해"처럼 이름을 지목해도 됩니다.

07 / 08
증상확인할 것
설치했는데 에이전트가 안 보임클로드코드를 재시작했는지, claude plugin list에서 활성화 상태인지 확인
업데이트해도 그대로임claude plugin marketplace update를 먼저 실행했는지 확인 후 재시작
malgnai-hub 도구가 실패함claude mcp list에서 연결·로그인 상태 확인. 로그인 창이 안 열리면 문의
토큰 사용량이 보고되지 않음클로드코드에서 "토큰 수집 에이전트 제대로 돌고 있어?"라고 물어보면 점검해 줍니다
