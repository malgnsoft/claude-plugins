## 1. 왜 결함인가 (변경 동결 예외 판정)

2026-08-19 provider 전환은 **기록처만** 바꿨다. 제품 `malgn-agent/` 본문에 박힌 `lesson \`8f36f1d3\`` 류 8자리 hex id는 malgnai-mcp(로컬, project_id `e3c8eba1-…`)에서 발급된 것으로, hub는 26자 ULID(`01m0h2x7n81g6ez252z0yx0w5f`)를 쓴다 — **형태가 곧 출처이며 둘은 호환되지 않는다.**

따라서 이 플러그인을 설치한 직원에게 이 id들은 **조회 수단이 전무한 죽은 참조**다. "지금 무엇이 깨져 있는가"에 답할 수 있으므로 개선이 아니라 **결함**이고, `CLAUDE.md` §"변경 동결 원칙"의 채택 대상(깨진 참조)에 해당한다. 사용자 직접 지시(2026-08-22)로 착수한다.

**목적**: 죽은 참조를 없애되, 그 참조가 지탱하던 **규칙의 의미는 한 글자도 잃지 않는다.**

5. **`commit \`13bcd60\`` 같은 7자리 git 해시** — 이 저장소에서 `git show`로 조회 가능한 살아있는 참조다. 유지.

## 3. 처리 규칙 — 패턴 3분류

### A. 순수 출처 꼬리표 — 기계 처리 (156건)

`…재사용합니다(lesson \`8f36f1d3\`).` 처럼 괄호 안이 id뿐인 경우.

- **처리**: 선행 공백 포함 괄호째 삭제.
- **정규식**: `\s*\((?:lesson|decision|issue|memory) \`[0-9a-f]{8}\`(?:[,/·]\s*\`[0-9a-f]{8}\`)*\)`
- **근거**: 규칙의 실질은 이미 앞 문장에 서술돼 있고 id는 출처 꼬리표뿐이다. 삭제해도 행동 지시가 변하지 않는다.

### B. 사유·날짜 + id — 기계 처리, 사유는 보존 (42건)

`(2026-07-23 정정, lesson \`e8a738ed\`)` 처럼 괄호 안에 다른 정보가 함께 있는 경우.

- **처리**: `, lesson \`x\`` 부분만 삭제해 `(2026-07-23 정정)`으로 남긴다. **날짜·사유·경위는 그대로 둔다.**
- **정규식**: `([,，]\s*(?:lesson|decision|issue|memory) \`[0-9a-f]{8}\`(?:[,/·]\s*\`[0-9a-f]{8}\`)*)(?=\))`

### D. id가 문장 성분 — **개별 판단 (21건 / 18줄)**

기계 치환 금지. §4에 건별로 명세한다.

## 4. D 21건 — 건별 요구사항

> **작성 원칙**: 아래는 **"무엇이 참으로 남아야 하는가"**만 규정한다. **치환 문안은 trainer가 제안하고 PM이 검증한다** — 이 명세서에 대체 문장을 미리 써넣지 않는다.

### 4.1 🔴 최우선 — id가 **범위 한정자**인 것 (2건, 1줄)

| 위치 | 필수 요구사항 |
|---|---|
| `agents/qa-engineer.md:25` | 문장 후반 "이 자율권은 lesson \`d0bee328\`·\`574534fa\` **이 두 건에만 한정**되며…"에서 id가 **자율권의 경계**를 정의한다. 같은 줄 전반부에 두 유형의 서술(라우팅 회귀 / 인증 스모크)이 이미 있으므로, 후반부 한정자를 **그 서술을 가리키는 표현으로 치환**해 "정확히 두 유형"이라는 닫힌 경계가 유지돼야 한다. 기계 삭제하면 자율권이 무한정 열린다. `docs/methodology/audit-report.md:103`이 이 문장을 "열린 수량어 제거 모범 사례"로 인용 중 — **역참조가 여전히 성립하는지 확인**(성립하지 않으면 PM에게 보고, docs 수정은 PM이 한다) |

### 4.2 🟠 반복 복제된 정책 꼬리표 (2건)

`decision \`912221a4\``("자율 실행 가능 판단 유형, 2026-07-23 부하 인터뷰 기반 확대")가 여러 에이전트에 **동일 문구로 복제**돼 있다. 베이스 실측 기준 D로 남은 곳은 `agents/qa-engineer.md:25` · `agents/frontend-dev.md:28` 2곳이고, 나머지 복제본(`architect.md` · `ux-designer.md`)은 A/B 패턴으로 자동 처리된다.
